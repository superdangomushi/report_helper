# report_helper

実験レポートの Word ファイル（.docx）を、Markdown と画像から自動で組み立てるツールです。
表紙・目次・章立て・図表番号・式番号・引用文献の整形を全部やってくれます。

このページは **インストールと最初のレポート作成までの手順** をまとめたものです。
プログラミング経験がなくても進められるように書いてあります。

---

## 1. ファイルをダウンロードする

このページの右上にある緑色の **`<> Code`** ボタンを押し、
**`Download ZIP`** を選んでください。

ダウンロードできたら、ZIP ファイルを **解凍（展開）** します。

> 解凍したフォルダはどこに置いても構いません。
> 例: デスクトップや「ドキュメント」フォルダの中など、自分でわかりやすい場所に置いてください。

---

## 2. インストールする

お使いの OS に合わせて、どちらか片方の手順で進めてください。

### 🪟 Windows の場合

1. 解凍したフォルダを開きます。
2. その中にある **`install.bat`** をダブルクリックします。
3. 「ユーザーアカウント制御」のダイアログが出たら **「はい」** を押してください。
4. 黒い画面が開き、自動で次のことが行われます:
   - Node.js のインストール（無ければ自動で入ります）
   - 必要な部品のダウンロード
   - `mkreport` コマンドの登録
5. 最後に「完了しました。」と表示されたら、Enter キーを押して閉じてください。

> **何もインストールされていない PC でも、これだけで使えるようになります。**
> 途中で何か聞かれることはありません。

### 🍎 macOS の場合

1. まず **Homebrew** が必要です。
   入っていない場合は <https://brew.sh> の手順でインストールしてください。
2. ターミナルを開きます（`command + space` → 「ターミナル」と入力）。
3. 解凍したフォルダの中に移動します。
   ```sh
   cd ~/Downloads/report_helper-main     # 例。実際のパスに置き換えてください
   ```
4. インストールスクリプトを実行します。
   ```sh
   ./install.sh
   ```
5. 最後に「完了しました。」と表示されれば成功です。

---

## 3. 最初のレポートを作ってみる

インストールが終わったら、ターミナル（Mac）または PowerShell（Windows）を開いて、
レポートを置きたいフォルダに移動してから次のコマンドを入力します。

```sh
mkreport start my_first_report
```

`my_first_report` という名前のフォルダができ、中にひな型が入っています。

```
my_first_report/
├── README.md          ← 書き方の詳しい説明
├── title.env          ← 表紙（タイトル・氏名・日付など）
├── 1mokuteki.md       ← 1. 目的
├── 2souchi.md         ← 2. 実験装置
├── 3houhou.md         ← 3. 実験方法
├── 4kekka.md          ← 4. 実験結果
├── 5kousatsu.md       ← 5. 考察
├── 6inyou.env         ← 6. 引用文献
├── figures/           ← 図の画像
└── ocr_hyo/           ← OCR で読み取りたい表の画像
```

中の `.md` ファイルをメモ帳・テキストエディット・VS Code などで開いて、
**普通の文章を書くだけ** でレポートが組み立てられます。

書き終わったら、フォルダの中で次のコマンドを実行します。

```sh
mkreport .
```

すると `my_first_report.docx` という Word ファイルができあがります。
ダブルクリックで開いてください。

---

## 4. できること（ざっくり）

- **表紙の自動生成**: `title.env` に氏名・実験項目・日付などを書くだけで表紙が完成します。
- **章立て・通し番号**: 図番号・表番号・式番号は自動で付きます。
- **Markdown の表** → Word の表に変換。
- **画像の表を Gemini API で OCR** して、Word の表として埋め込みます（任意機能）。
- **LaTeX 風の数式** を `(1), (2), ...` の番号付きで挿入。
- **句読点の自動変換**: `、` `。` は規約に合わせて `,` `.` に自動で置き換わります。元のファイルは書き換え不要です。

---

## 5. 詳しい書き方

ひな型を作ると、その中に `README.md` が入っています。
そこに、次のような書き方が一通り書かれています:

- `title.env` の各項目
- 図・表・数式の挿入方法
- 整列マーカー（中央揃え・右揃え）
- 引用文献の書き方
- Gemini OCR の API キーの設定方法

困ったらまずそちらを見てください。

---

## 6. うまく動かないとき

| 症状 | 対処 |
|------|------|
| Windows で `install.bat` をダブルクリックしても何も起きない | ファイルを右クリック →「管理者として実行」 |
| `mkreport` コマンドが見つからないと言われる | PowerShell / ターミナルを一度閉じて開き直してください |
| OCR の表が「失敗」と書かれている | `.env` ファイルに `GEMINI_API_KEY=...` を書いてください（詳しくはプロジェクト内 README） |
| Mac で `./install.sh: Permission denied` と出る | `chmod +x install.sh` を実行してから再度 `./install.sh` |
