# レポート作成ガイド

このフォルダのファイルを編集してから、次のコマンドでレポート（.docx）を生成します。

```sh
mkreport <このフォルダのパス>
# 例:
mkreport .                    # カレントディレクトリから生成
mkreport ./my_first_report    # 別フォルダから生成
```

生成された `.docx` はプロジェクトフォルダ内に `<プロジェクト名>.docx` として保存されます。出力先を変えたい場合は第2引数で指定します。

```sh
mkreport ./my_first_report ~/Desktop/レポート.docx
```

```

#9=15:30
```

| キー | 位置 |
|------|------|

## 本文（.md ファイル）の記法

### 句読点の自動変換

レポート規約に合わせて、本文・表・タイトル・引用に含まれる全角の `、` と `。` は、生成時に自動で半角の `,` と `.` に変換されます。元の `.md` / `title.env` / `6inyou.env` は書き換えずそのままで構いません（数式や画像ファイル名は変換対象外）。

### 段落

普通にテキストを書けば段落になります。空行で段落が分かれます。

### 表（Markdown）

```
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| a   | b   | c   |
| d   | e   | f   |
```

`hyo1.docx` の罫線スタイル（上ダブル線・左右なし）で出力されます。

### 図の挿入

```
` ` ` 1-1-1ファイル名.png ` ` `
```

（実際は半角バッククォート3つで囲ってください）

`figures/` に置いた画像を挿入し、その下に中央揃えで `図1.1.1 ファイル名` のキャプションを自動で付けます。

**ファイル名の命名規則**: `N-N-N<名前>.<拡張子>`
- `1-1-1温度分布.png` → 「図1.1.1 温度分布」
- `2-3-1グラフ.jpg`   → 「図2.3.1 グラフ」

### OCR 表（Gemini）

```
` ` ` 1-1-1表名.png ` ` `
```

`ocr_hyo/` に置いた表の画像が Gemini API で OCR され、Markdown 表として認識されてから docx の表として埋め込まれます。
画像上に中央揃えで `表N.N.N <名前>` のキャプションを付けます。

**`--ocr` フラグでのみ実行**: API 呼び出しを伴うので、明示的に `--ocr` を付けたときだけ OCR が走ります。

```
mkreport --ocr ./my_first_report          # OCR 実行
mkreport ./my_first_report                # OCR スキップ（キャプションだけプレースホルダ表示）
```

**OCR 結果は .md に書き戻される**: OCR が成功すると、元の `.md` の `` ```ファイル名.png``` `` のフェンスが下記のブロックに置き換えられます。

```
<OCR-2-1-1計測値表.png>
/c 表2.1.1 計測値表 c/

| 試料 | 値1 | 値2 |
| --- | --- | --- |
| A | 100 | 200 |
</OCR-2-1-1計測値表.png>
```

- これ以降、`--ocr` なしで build しても表は描画されます（キャッシュ）。
- 中身を手で編集すれば編集後の表が出力されます。
- `--ocr` をもう一度付けて build すると、ブロック内が新しい OCR 結果で上書きされます（やり直したいとき用）。

**APIキー設定**: プロジェクト直下の `.env` か環境変数で:

```
GEMINI_API_KEY=your_api_key_here
```

**失敗時の挙動**: APIキー未設定・無効・通信失敗・解析失敗のいずれも、エラーで止まらずに表の位置に「失敗」とだけ書き込みます。

### 数式

````
```
E = mc^2
```
````

連番で `(1), (2), ...` の式番号が右端に振られます（セクションをまたいで通し番号）。

**数式記法（LaTeX 風）**:

| 記法 | 意味 | 例 |
|------|------|-----|
| `x^2` | 上付き | x の2乗 |
| `x^{2y}` | 上付き（複数文字は `{}` で括る） | x の2y乗 |
| `x_1` | 下付き | x_1 |
| `T_corr` | 下付き（連続する英字は `{}` 不要） | T_corr |
| `x_{ij}` | 下付き（複数文字） | x_{ij} |
| `\frac{a}{b}` | 分数 | a/b（バー付き） |
| `\sqrt{x}` | 平方根 | √x |
| `\sqrt[n]{x}` | n乗根 | ⁿ√x |
| `*` | 積 | × |
| `\bar{x}` | バー | x̄ |
| `\hat{x}` | ハット | x̂ |
| `\vec{v}` | ベクトル | v⃗ |
| `\dot{x}`, `\ddot{x}` | ドット | ẋ, ẍ |

**ギリシャ文字**: `\alpha`, `\beta`, `\gamma`, `\delta`, `\epsilon`, `\zeta`, `\eta`, `\theta`, `\iota`, `\kappa`, `\lambda`, `\mu`, `\nu`, `\xi`, `\pi`, `\rho`, `\sigma`, `\tau`, `\upsilon`, `\phi`, `\chi`, `\psi`, `\omega`（先頭大文字版もあり: `\Gamma`, `\Delta`, ... `\Omega`）

**演算記号・関係子**: `\pm`, `\mp`, `\times`, `\cdot`, `\div`, `\le`, `\ge`, `\ne`, `\approx`, `\equiv`, `\sim`, `\propto`, `\ll`, `\gg`

**矢印**: `\to`, `\rightarrow`, `\leftarrow`, `\Rightarrow`, `\Leftarrow`, `\Leftrightarrow`, `\mapsto`

**大型演算子**: `\sum`, `\prod`, `\int`, `\oint`, `\iint`, `\iiint`

**集合・論理**: `\in`, `\notin`, `\subset`, `\supset`, `\cup`, `\cap`, `\emptyset`, `\forall`, `\exists`, `\land`, `\lor`, `\lnot`

**その他**: `\infty`, `\partial`, `\nabla`, `\hbar`, `\ell`, `\prime`, `\cdots`, `\ldots`

**関数（直立体で表示）**: `\sin`, `\cos`, `\tan`, `\log`, `\ln`, `\exp`, `\max`, `\min`, etc.

**例**:

````
```
\sigma = \sqrt{\frac{1}{N} \sum (x_i - \bar{x})^2}
```
````

### 整列マーカー

C++のブロックコメント風に `/c ... c/` と `/r ... r/` で囲った範囲を中央／右揃えにできます。マーカーが無い箇所は左揃え（既定）です。複数段落をまたいでも有効です。

```
/c
この段落は中央揃え。
複数行もOK。
c/

何もない段落は左揃え。

/r この一文は右揃え。 r/
```

## 6inyou.env（引用）

1行 = 1件の引用。CSV 形式で `年,著者,タイトル` の順に書きます。

```
2026,速稲田大学理工学術院,あいうえお
2025,北川,書きくけこ
```

Word では次のように番号付きで出力されます:

```
[1] 速稲田大学理工学術院, あいうえお, 2026.
[2] 北川, 書きくけこ, 2025.
```

## コマンド一覧

| コマンド | 説明 |
|----------|------|
| `mkreport start <プロジェクト名>` | テンプレートからプロジェクトを新規作成 |
| `mkreport <プロジェクトパス>` | プロジェクトからレポートを生成 |
| `mkreport <プロジェクトパス> <出力>` | 出力先を明示してレポートを生成 |
| `mkreport help` | 使い方を表示 |
